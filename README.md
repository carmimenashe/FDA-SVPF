# תיק מגדלים

אפליקציית ניהול מסמכי מגדלים: מעקב תעודות, בדיקות מעבדה, התראות תפוגה, הפקת חבילת מסמכים ללקוח, ויומן רגולטורי מול ה-FDA.

קובץ HTML יחיד + Supabase. אין שלב build.

## מה בפנים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה |
| `schema.sql` | טבלאות, הרשאות ונתוני פתיחה |

## התקנה

**1. Supabase**

צור פרויקט חדש. פתח SQL Editor, הדבק את כל `schema.sql`, הרץ.
בטאב Authentication ← Users ← Add user, צור לעצמך משתמש עם אימייל וסיסמה. זה המשתמש שאיתו נכנסים.

**2. GitHub**

```
git init
git add index.html schema.sql README.md
git commit -m "תיק מגדלים"
git branch -M main
git remote add origin git@github.com:USER/REPO.git
git push -u origin main
```

**3. Netlify**

Add new site ← Import an existing project ← בחר את המאגר.
Build command: השאר ריק. Publish directory: `.`

**4. חיבור**

בכניסה הראשונה האפליקציה מבקשת Project URL ו-anon public key. שניהם ב-Supabase תחת Project Settings ← API. הם נשמרים בדפדפן.

אם אתה מעדיף להטמיע אותם בקוד, מלא בראש ה-`<script>`:

```js
const BUILT_IN_URL = 'https://xxxx.supabase.co';
const BUILT_IN_KEY = 'eyJ...';
```

ה-anon key מיועד לחשיפה בצד לקוח. ההגנה היא ה-RLS: בלי התחברות אין גישה לנתונים.

## מבנה הנתונים

**growers** — מגדל, GGN, תעודה ותוקפה, מוצרים, ותדירות הדגימה הרצויה בימים (`residue_days`, `micro_days`). התדירות היא מה שמזין את ההתראות.

**documents** — כל בדיקה ומסמך. שדות שכדאי לא לדלג עליהם: `sampled_on` (התאריך שנחשב לחלון הלקוח), `criterion` (מול מה נבחן — EC 396/2005 או 40 CFR 180), `reviewed_on` ו-`reviewed_by` (הסקירה החתומה), ו-`link` לקובץ בדרייב.

**reg_log** — יומן מול רשויות. להגשות יוצאות יש שדות אישור קליטה נפרדים.

הקבצים עצמם נשארים בדרייב. האפליקציה מחזיקה שורות וקישורים.

## המסכים

**מצב** — חריגים פתוחים, ואחריהם שורה לכל מגדל עם שלוש נקודות: תעודה, שאריות, מיקרוביולוגיה. ירוק תקין, כתום מתקרב, אדום חורג.

**מגדלים** ו**מסמכים** — הזנה ועריכה.

**חבילת לקוח** — בוחרים מגדל וחלון של 3, 6 או 12 חודשים ומקבלים דף שער באנגלית: פרטי המגדל, התעודה, טבלאות הבדיקות בחלון, ורשימת המסמכים המצורפים. אם החלון ריק, המסמך אומר זאת במפורש במקום להשמיט. אפשר להעתיק או להדפיס ל-PDF.

**FDA** — היומן הרגולטורי.

## הערות

התאריך הקובע לחלון הלקוח הוא תאריך הדגימה, לא תאריך הדוח. זה ההבדל שלקוח סופר.

מסמך שנכשל או שנמצא בהסתייגות נשאר בתיק עם הסימון שלו. רשומה שמציינת מה לא התקבל חזקה מרשומה שמאשרת הכל.

מחיקת מגדל מוחקת גם את כל המסמכים שלו.
